# Original AI-session evidence

This local directory contains an unmodified native Codex JSONL snapshot, not a reconstructed transcript. The JSONL and integrity manifest are excluded from public Git and must accompany the PDF separately for course submission.

An active chat can append records after copying. Run `pwsh -File scripts/refresh_session_export.ps1` after the final response to refresh the finalized original. The command changes no record content. Verify the source and target SHA-256 hashes match. Instructor acceptance of native Codex JSONL instead of an OpenCode-specific JSON export remains unconfirmed.

The unrelated `Downloads/Telegram Desktop/session.json` contains only `WARNING_BANNER` and is not used as an original session export.
